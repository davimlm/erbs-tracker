a. Metas
Meta Principal: Criar uma aplicação web interativa que cruze a localização das antenas (ERBs) com dados populacionais para identificar e visualizar "gargalos de infraestrutura" (áreas com alta população e baixa cobertura) no Brasil.

b. Objetivos
Obter e limpar a base de dados nacional de ERBs da Anatel.

Obter e processar os dados populacionais e a malha geográfica municipal do IBGE.

Desenvolver um algoritmo/script matemático para calcular o índice de "habitantes por ERB" e mapear o raio de alcance baseado nas frequências (700MHz, 2600MHz, 3500MHz).

Desenvolver a interface front-end (HTML, CSS, JS) utilizando a biblioteca Leaflet.js para renderização do mapa.

Integrar os dados tratados à interface para permitir filtros dinâmicos por operadora, tecnologia e região.

c. Entregáveis
Base de Dados Consolidada: Arquivo tratado cruzando Anatel e IBGE.

Repositório de Código: Código-fonte da aplicação (scripts de processamento Python + front-end web).

Prova de Conceito (PoC) Funcional: O aplicativo web rodando no navegador com o mapa interativo, painel de métricas e filtros.

Apresentação Final: Slides contendo o contexto, a metodologia e a demonstração dos resultados.
